# VoltaSegura — App Mobile (React Native/Expo)

App do cidadão (estudante do período noturno): consulta rotas, compara alternativas e recebe informações com indicação de confiança.

> ⚠️ Em construção. Stack: React Native + TypeScript + Expo Router, consumo de API/mock, banco de dados local. A jornada principal segue o fluxo "Planejar → Analisar → Comparar → Decidir → Revisar (ida e volta)" do documento vivo.

## Requisitos do README da disciplina (neste app)

1. Ficha da CitizenTech (link/copiar do README raiz);
2. Instruções para rodar o app;
3. Prints das telas;
4. Link do vídeo de até 3 min.
